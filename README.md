# Asteroids

A recreation of the classic Asteroids arcade game built with Python and Pygame as part of the Boot.dev Backend curriculum.

## Features

- Ship movement and rotation
- Projectile system
- Asteroid spawning
- Collision detection
- Asteroid splitting
- Object-oriented architecture
